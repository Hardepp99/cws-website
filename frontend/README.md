# CWS Frontend (Next.js)

Public site, admin panel, and CMS API (`/api/v1`) in one app.

## Setup

1. Copy `.env.example` → `.env.local` (MySQL + `CWS_UPLOAD_DIR`).
2. From repo root, ensure `data/uploads/` has media files.
3. `npm install` && `npm run dev`

- Site: http://localhost:3000  
- Admin: http://localhost:3000/admin  
- API: http://localhost:3000/api/v1/settings  

See [../docs/NODE_CMS.md](../docs/NODE_CMS.md).
