# CWS Website — URLs (local)

## Next.js (use this)

| URL | Description |
|-----|-------------|
| http://localhost:3000 | Public site |
| http://localhost:3000/admin | Admin panel |
| http://localhost:3000/api/v1/settings | CMS API (JSON) |

```bash
cd frontend
npm run dev
```

## Database

- MySQL database: `cws_cms`
- Schema: `database/schema.sql`
